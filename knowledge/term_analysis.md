#### 二、等级评定标准
```markdown
### 2.1 国标评定（高速公路）
| 指标 | 优         | 良          | 中          | 次          | 差   |
|------|------------|-------------|-------------|-------------|------|
| PQI  | ≥90        | ≥80, <90    | ≥70, <80    | ≥60, <70    | <60  |
| PCI  | **≥92**    | ≥80, <92    | ≥70, <80    | ≥60, <70    | <60  |

### 2.2 省标评定（示例）
| 指标 | 达标       | 合格不达标    | 不合格      |
|------|------------|---------------|-------------|
| PCI  | ≥92        | ≥80, <92      | <80         |
| RDI  | ≥90        | ≥80, <90      | <80         |
| 计算公式：PQI省标 = 0.35*PCI + 0.15*RDI + 0.4*RQI + 0.1*91.5 |
```

#### 三、病害分类与字段映射
```markdown
### 3.1 病害类型及数据库字段
| 病害大类 | 子类         | 字段名                  | 注释                          |
|----------|--------------|-------------------------|-------------------------------|
| 裂缝类   | 龟裂         | `crack_scale`           | 病害规模（㎡/车道公里）       |
|          | 块状裂缝     | `block_crack_area`      | 块状裂缝面积                  |
| 变形类   | 沉陷         | `settlement_area`       | 沉陷面积                      |
|          | 车辙         | `car_withdrawal`        | 车辙面积                      |
| 修补类   | 裂缝修补     | `crack_area_repair`     | =块状修补+横向修补+纵向修补   |

### 3.2 关键计算公式
- **病害修补率**：`disease_repair_rate = 修补类面积 / 病害总面积`
- **裂缝修补率**：`crack_repair_rate = 裂缝修补面积 / (裂缝面积 + 裂缝修补面积)`
```

#### 五、典型查询场景模板
```markdown
### 5.1 路段指标趋势分析
```sql
-- 查询某路段2023年PCI月均值
SELECT 
  DATE_FORMAT(check_year, '%Y-%m') AS 月份,
  AVG(pci) AS 平均PCI
FROM evaluation_0227_to_li
WHERE highway_segment_id = 200 
  AND check_year BETWEEN '2023-01-01' AND '2023-12-31'
GROUP BY 月份
```

### 5.2 管养单位达标率统计
```sql
-- 统计各管养单位PCI达标率（省标）
SELECT 
  d.dept_name AS 管养单位,
  COUNT(CASE WHEN e.pci_sp = 1 THEN 1 END) / COUNT(*) AS 达标率
FROM evaluation_0227_to_li e
JOIN blade_dept_0227_to_li d ON e.management_unit_id = d.id
WHERE e.data_source = 2  -- 省检数据
GROUP BY d.dept_name
```

### 知识库使用说明
1. **术语查询**：直接搜索缩写（如PQI）获取定义及关联字段；
2. **公式调用**：输入“裂缝修补率公式”返回`crack_repair_rate`计算逻辑；
3. **图表生成**：描述需求（如“各路段PCI热力图”）自动映射字段与可视化规则。
